# Online Study Test (Version 3)

**Online Study Test** is an Android application designed for online learning, focusing on secure and efficient video content delivery. Initially, the app included sections for exams, tests, PDFs, and videos. In Version 3, the app now exclusively focuses on the **Video Section**, with enhanced security features to ensure a seamless and secure user experience.

---

## Key Features

1. **Video Section**  
   - Access high-quality educational videos tailored for effective learning.
   - Optimized UI for smooth navigation and video playback.

2. **Enhanced Security**  
   - **Screenshot Disable**: Prevents capturing or sharing video content to maintain confidentiality.  
   - **Single User Login**: Ensures one account is active on a single device at any time, reducing account misuse.

3. **Demo Account**  
   - Provides users a demo experience to explore the platform before committing.

---

## How to Use

1. **Login**: Authenticate using your credentials (single login per account is enforced).  
2. **Browse Videos**: Access the available video library for your courses.  
3. **Demo Mode**: Use the demo account to explore app functionality.
